# Gate C — canonical Word by Word captions

The A/B artifacts compare the compact treatment with the P31 Word by Word
treatment. Word activation uses canonical narration start/end frames; the
adapter does not split or independently stagger caption copy.

- `compact-caption-frame-30.png`: baseline compact treatment.
- `word-by-word-caption-frame-30.png`: canonical word-timed treatment.
- `word-by-word-caption-proof.mp4`: short timing proof.

Automated fixtures cover short, medium, punctuation-heavy, and fast cues. They
also verify stable two-line layout, punctuation attachment, exact transcript
projection, immutable token props, and that the transcript caption is not a
duplicate standalone Remotion Bit.
