# 6-Phase Architecture & Answer Format

## 1. The 6-Phase Retention Architecture

| Phase | Window | Core Objective & Roster Duties |
| :--- | :--- | :--- |
| **P1 OPEN** | 0:00 – 1:30 | **0–3s Microhook** (concrete, surprising word LAST; screen already moving, no greeting/atmosphere) -> **0:08 Paradox** (pay hook wrong) -> **0:08–0:30 Story Engine** (stakes, biography twist) -> **0:30–1:00 Rehook #1** (partial value + dated calculable promise; licensed triad) -> **1:00–1:30 Rehook #2** (opponent named as a MECHANISM, abstractions cashed). |
| **P2 ENGINE** | to ~17% | Catalyst closed micro-loop (BUT/THEREFORE joins) -> Plant the **Head-Fake** straight without tipping hand -> Rehook + Promise-tease near 10% -> Macro loop 1 closes on bigger question. |
| **P3 GAP** | to 45% | 5-step anecdote/reflection units (Ira Glass engine; 2:00–2:30 each) -> Bank best evidence for last pre-pivot unit -> Final promise-tease ~27% (zero promises after this). |
| **P4 PIVOT** | 45% – 55% | Scripted pause -> Contracted punchy reversal -> **Central object flips meaning** -> Zero CTAs. |
| **P5 REFLECTION** | to ~87% | Chiastic center -> **Grand Payoff at 60–70%** (promised calculation happens at viewer scale; never "as promised") -> Reverse-order loop closures -> **The Tell** (variable + threshold + position + flip condition) -> >= 2 savor beats. |
| **P6 CLOSE** | Final 60–90s | **Ring Echo** (opening image returns transformed, never narrating symmetry) -> **Final Triad** fused with anaphora resolution -> Single CTA (15–30s post-payoff) -> Tonight's action assignment. Hard stop. |

## 2. Doc 35 Answer Format (The 8-Beat Matrix)

When answering competitor videos or market consensus:

| Beat | Strategic Function | Enforcement Rule |
| :--- | :--- | :--- |
| **1. Credit** | Generously acknowledge their thesis and presentation | Name the creator/source; never dismiss them |
| **2. Steelman** | Acknowledge their strongest argument | Prove we understand their data better than they do |
| **3. Agree** | Confirm what their numbers got right | Establish baseline shared reality |
| **4. Locate** | Pin the exact seam where their model expires | Cite the missing structural mechanism |
| **5. Relocate** | Shift the problem to the true bottleneck | Reframe the conclusion rather than denying it |
| **6. Mechanism** | Unpack the causal plumbing | Explain *why* the consensus relationship broke |
| **7. Consequence**| What the market is mispricing | Contrast consensus belief with primary filing data |
| **8. Escalate** | The deeper macro/technological moat | Show the asymmetry is even larger than anticipated |
