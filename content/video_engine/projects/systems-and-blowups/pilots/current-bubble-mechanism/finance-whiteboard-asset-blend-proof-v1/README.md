# Finance Whiteboard Asset Blend Proof

An isolated, proof-only HyperFrames composition for testing PDF-derived
whiteboard cards alongside the recurring P25 face-readable character.

- 1920×1080 authoring, 1280×720 review, 24 fps
- 18 seconds from the approved P24 narration/audio window
- three source-bound cards, one active semantic asset at a time
- real marker-hand cutout riding cap-safe serpentine mask reveals and tracing
  selected detail connectors
- no provider calls and no generated factual text

Run `python ../../../../../../scripts/build_finance_whiteboard_asset_proof.py
--render` from the repository root to stage inputs, run HyperFrames checks,
render the MP4, and create the boundary packet.
