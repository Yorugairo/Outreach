# Finance Whiteboard Code-Drawn MVP

An isolated P27 HyperFrames proof for a warm whiteboard plate with a restrained
woodblock texture, upper-left topic label, and detailed code-assisted artblocks.
Each artblock is generated locally as a finished PNG and revealed through the
whiteboard-explainer mask/hand contract; no PDF panel is used in the visual path.

- 1920×1080 authoring, 1280×720 review, 24 fps
- 18 seconds from the approved P24 audio/word receipt
- real draw-A hand plus deterministic mirrored draw-B pose
- contact sheet and coverage chunks under `review/`
- no provider calls and no runtime factual text generation

Run from the repository root:

```powershell
python content/video_engine/scripts/build_finance_whiteboard_code_drawn_proof.py --render
```
