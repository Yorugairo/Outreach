# Current Bubble — HyperFrames object choreography

This is a dark, warm woodblock-paper theatre for a finance explainer. The world
stays alive while the causal object changes scale, position, and hierarchy.

Use the approved plates as authored surfaces, not as unrelated full-frame cuts.
The elevator, memory stack, factory gate, index-fund container, bottleneck, and
inspection lamp are the visual nouns. Motion must make the active verb legible.

Avoid generic pulses, decorative diagrams, persistent evidence rails, and
randomly selected plates. Evidence appears as a short local card only when the
spoken claim calls for it.
