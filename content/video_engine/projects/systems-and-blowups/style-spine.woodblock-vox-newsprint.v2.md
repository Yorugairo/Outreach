# Style Spine v2 — woodblock vox newsprint (finance channel)

Correction of record (operator, 2026-08-25): generation drifted toward
"paper collage" because claim prompts carried collage language. World
plates are prompted as **woodblock vox newsprint**. Washi paper texture is
RESERVED for the evidence-dock chrome (the translucent layer evidence is
pasted onto in the edit) — it never appears in world-plate prompts.

## STYLE BLOCK (verbatim, every world/host slot)

```
STYLE (verbatim, applies to this subject): woodblock vox newsprint —
carved woodblock ink contours with visible cut character, flat editorial
newsprint color fields, crisp registration like a fine art print. Bold
clean silhouettes readable at small size. Subtle newsprint grain allowed;
NO paper-collage layering, NO torn deckle edges, NO washi texture — flat
carved-print surfaces only. Matte, never glossy, never photographic.
Palette strictly: cream #F4E6C7, charcoal #25313C, cobalt #1769C2, teal
#178C83, sunflower #F5B72E, coral #ED6A4A. Adult editorial tone,
financially credible, never childish.
LIGHT: soft even light from the upper left, gentle shadow falling lower
right, low contrast. Camera eye-level, straight-on, no perspective
distortion.
HARD RULES: no readable text, letters, numbers, logos, or watermarks
anywhere; documents show only illegible engraved scrollwork; no
real-person likeness; no flags or political symbols.
```

## HOST IDENTITY ANCHOR (verbatim wherever the host appears)

```
THE HOST (identity anchor, exact): an adult Black man with sculpted loc
twists and a trimmed goatee, black rectangular glasses, deep-indigo suit,
copper tie, small gold lapel pin. Same face structure, hair, glasses, and
wardrobe in every image — condition on the supplied reference images.
Confident, composed, warm; never caricatured.
```

## WORLD-BOARD OVERRIDE (verbatim on world_board slots)

```
WORLD BOARD OVERRIDE for this slot only: generate landscape 1536x1024;
the flat opaque image IS the deliverable - flatten to RGB (no alpha
channel), skip matting; save the same file as both source/ and objects/
paths.
```

Quiet-zone rule: keep one side of the frame visually quiet (mostly bare
cream or charcoal) as a clear zone for later data overlay.
