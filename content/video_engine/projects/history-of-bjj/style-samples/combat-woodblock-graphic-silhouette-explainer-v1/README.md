# Combat Woodblock Graphic Silhouette — Sample Set

Three original calibration plates for the versioned profile
`combat-woodblock-graphic-silhouette-explainer-v1`:

1. `01-threshold-hook.png` — use the foreground actor and one changed object
   to introduce a story question.
2. `02-community-route-correction.png` — use separated role silhouettes and a
   route signal to make a historical/cultural correction legible.
3. `03-leverage-metaphor.png` — use one grounded physical action to clarify a
   concept without teaching a technical sequence.

These samples are original calibration material, not history evidence and not
automatic renderer inputs. Inspect them with the style profile and generate a
fresh, job-local asset manifest before any production use. Facts, dates,
citations, and labels remain local editorial elements.

See `sample-set.manifest.v1.json` for immutable file hashes and intended use.

`historical-editorial-wave-032/` preserves the approved twelve-plate Episode 1
review set plus its contact sheet. It is deliberately a calibration set: a
clone may learn the asset grammar and inspect composition coverage, but still
must use its own prompt plan and asset promotion before any render.
