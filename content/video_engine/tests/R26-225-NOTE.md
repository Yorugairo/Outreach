# R26-225 — the gate test no longer rewrites episode one's committed report

**2026-09-18.** A full suite run dirtied
`content/video_engine/projects/systems-and-blowups/steel-and-paper/build-f/GATES-MOTION.md`
every time, and the lane reverted it by hand twice.

## The one offender

`content/video_engine/tests/test_motion_gate_wiring.py` —
`test_ep1_report_is_the_four_fail_baseline` called
`G.write_report(BUILD, "steel-and-paper.timeline.json")` on the real `build-f`.
`write_report` writes `GATES-MOTION.md` **beside the timeline** it measures (that is the
gate's contract, read by `render_episode.py`), so running it on a project's committed build
rewrites the committed record as a side effect of a test.

Fixed by `_ep1_bed(tmp_path)`: a private copy of build-f's gate inputs (every top-level
`*.json` beside the timeline, plus `player.html` only when one of the hash-keyed measurement
files — `frame-hashes*.json`, `morph-invariants.json`, `layout-probe.json` — is there for the
staleness check to judge against it). The copy keeps the dir name `build-f`, so the report
header (`# MOTION GATE — build-f`) and the stats are the ones ep1's own build produces and
**every assertion stayed byte-identical** — the report path, the FAIL count, the header, the
`[FAIL ] M01` row, the RESULT alternatives and the VERDICT line.

Proof the bed is gate-equivalent: the test failed with the *same* number before and after the
redirect (`assert 9 in (7, 8)` at `test_motion_gate_wiring.py:30` before, `:51` after) — the
gate reads the copy exactly as it read the build.

Every other write in `content/video_engine/tests/` already goes to `tmp_path` or a fixture.

`test_morph.py:259` — all `tmp_path`), writes whose target derives from a project constant

(`25 failed, 1806 passed, 6 skipped in 720.81s` - the 25 are the pre-existing failures of R26-224's
class, this one among them), after which
`git status --porcelain --untracked-files=no -- content/video_engine/projects/` is EMPTY and
`git status --porcelain -- .../build-f/` is byte-identical to the pre-run snapshot (six untracked
`*-proof.html` / preview files that belong to other lanes, no tracked change).
