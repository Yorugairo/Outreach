Operator: "you're being very verbose and not very clear about cause and
outcome/impact." Said while answering a yes/no decision (recording
refusal) that I had explained three times without once stating it as
cause -> outcome.

**Why:** the operator decides fast when the shape is "if X, then Y
happens, which prevents Z." Paragraphs of rationale hide the decision.

**How to apply:** for any decision or status, lead with one line each:
CAUSE (the trigger), OUTCOME (what the system does), IMPACT (what it
prevents or costs). Detail only if asked. Keep option questions to one
sentence per option.
