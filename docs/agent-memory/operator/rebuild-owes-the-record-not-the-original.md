The operator, on the Tokyo v2 render with VidIQ's pre-publish read beside it (2026-09-18): *"now that i'm looking
again, we actually are missing a lot of the life mechanics - the chart's don't have life, the titles/labels don't
have life, we aren't using much/if any pans/camera work/kens burns. also, the short should probably open on the
chart axes, we can easily dock the tea clip in the chart's empty space. These are all ideas we have had before, but
VidIQ backs it independently."*

**Why:** my treatment for v2 read the record for the transitions and the cards (the melt, the snap, the room) and
carried the approved rows for everything else - so v2 had one idle token in the whole cut where the door and
calendar cuts carry `idle=live` on every page and `idle=drift` on every plate (E49). The same fault as the survival
count of s73: what the original had is not what the record owes.

**How to apply:** before any link, run the checklist against the RECORD's universal owes, not the reference cut:
count the idle tokens (every page live, every plate drifting), the camera on every named datum (s76), the open on the
axes with the hook's clip docked in the room (E73, E44), the captions' contrast over light plates, cues bound, the
outro. A rebuild that drops any of them owes a departure line. An external forecast (VidIQ) is a witness cited beside
the record's line, never a ruling. See [rebuild-is-not-a-base](rebuild-is-not-a-base.md), [fewer-cuts-directional-flow](fewer-cuts-directional-flow.md),
[nothing-ever-goes-truly-still](nothing-ever-goes-truly-still.md).
