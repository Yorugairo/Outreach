still image, just talking about 'how to be a zen trader' - offering
literally zero actual value, just an AI-generated script. So it's fair to
say that deeply answering the package (thumbnail + title + hook) is really

that. And the voice: our voiceover is the other constant."

**Standing order (E27, in OPERATOR-RULINGS and DOCTRINE-CORE):**
1. The package is answered - the thumbnail poses it, the title is its
   words, the hook answers it, in the first sentence (E24: G45 proxy, J12
   judge, P36 viewer window 0 = "what were you promised / was it answered").
2. The voice is constant (docs 33/36, the voice pack).
3. Everything else - structure, retention clock, ledger page, motion menu,
   evidence - keeps the viewer the package earned; it cannot earn one.

**How to apply:** when prioritising any script or build work, check the
package-answer first; a script review that starts with structure has the
order wrong. Production is the multiplier, not the base.
