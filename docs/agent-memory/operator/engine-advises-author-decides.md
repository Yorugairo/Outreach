The operator, shown the data-centre prop exiled to a desk plate because the page's fit refused it: "the engine is being too controlling. the whole point of making our drawing capabilities using advanced math instead of using remotion or hyperframes was to give us more freedom, we should be able to manipulate props freely" - and the rigging / 2.5D / 3D work is meant to extend that freedom.

**Why:** the engine was built in-house precisely so the author has more freedom than a template tool; a placement search that REFUSES a row (or forces a mechanism onto another plate) is the tool overruling the story.

**How to apply:** when designing or reviewing a check, make placement/layout findings WARNs with numbers in the door's report (over data, over a label, under a floor, cut by the frame), and give the author an explicit override (an authored place, moves after landing). Keep refusals only for truth (E28 geometry = number; no fabricated figures) and for the invisible (off-stage). When a row gets pushed onto another world because the engine refused, surface it to the operator as a problem, not a solution. Built as P69 T26d. When the engine limits something, first ask whether the limit is the claim's truth or just how the thing happened to be built.
