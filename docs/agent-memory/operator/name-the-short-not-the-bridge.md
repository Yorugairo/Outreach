The one-shot short under `content/video_engine/projects/systems-and-blowups/normal-for-which-bridge/` is
**the Normal for Which short** (its build dirs: `review-v1`, `build-review`, `build-short`, `build-short-built`,
`build-short-axes`). "The bridge" on its own means the P46 lane bridge - `bridge_send.py`, `bridge_daemon.py`,
the packets to Gemini and Astra. The folder's `-bridge` suffix only records that the short arrived over that lane.

**Why:** 2026-09-15, after I wrote "the bridge build" for build-short-axes: *"calling it the bridge build is not good,
i thought you meant the bridge to gemini/gpt, i was thinking how does the bridge keep needing work that I didn't
know about lol"*.

**How to apply:** say "the Normal for Which short" (or `normal-for-which-bridge/build-short-axes` when the dir
matters). Reserve "bridge" for P46. Same rule for any project whose folder name carries a lane or tool word.
