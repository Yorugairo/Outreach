Astra is not one conversation: the operator runs several Codex Desktop sessions under that name (the MP-FED-LIQUIDITY
parent, a SCRIPT-REVIEW-CLEARANCE session, reviewers). On 2026-09-22 the aligning Astra session preserved gate
tolerance edits (the hook epsilon's 3.06 s acceptance, hyphen-token expansion, beat-window tolerance) that it "could not
attribute" to its receipts; the parent treated them as possible silent gate relaxations and ordered a justification
table. The operator: "those notes come from a different astra session and are legitimate."

**Why:** unattributable-to-this-session is not unattributable. Provenance lives in the operator's other threads, not
only in the receipts one session can read.

**How to apply:** when a lane flags work it cannot attribute, ask the operator in one line whether another session
owns it before ordering review of it; keep the review for thresholds with no owner at all. See [three-lane-harness](three-lane-harness.md),
[worktree-sprawl](worktree-sprawl.md).
