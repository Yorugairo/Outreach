**Binding a character on the new Flow UI:** New character → Add from project → Upload media →
*search the picker by filename and click that option* (the click creates the character; "Add
media" takes the first listed item instead — that bound the wrong sheet once) → type the name in
the Character name input → Done. Prompts then reference the character by name only. **A character edit ("What do you want to change?") cannot adopt a new reference** - it re-renders from the old image and returns a near-copy; to bind a sheet, create the character FROM the file and rename the old one.
