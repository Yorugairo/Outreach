should be springing badge/pills with callouts ... stamp on an icon or prop or dock a screenshot of our price tracker, or show a flight

**Why:** a light points at what is already there; a named thing should ARRIVE. The first take's fault was a full-size chart left floating
over the world plate, not the throw.

beat with only a light is a hole; a thrown page-sized card becomes the page by zoom or push (the card-becomes-the-chart family). See
[frames-inward-not-tokens-outward](frames-inward-not-tokens-outward.md), [rings-retired-e56](rings-retired-e56.md).
