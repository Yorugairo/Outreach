From the 35-passage highlight session over the writing-for-the-ear research
(2026-08-24; final 45 marks). Operator-NAMED as most important: **the Ira

composition** (callbacks closed LIFO; the ending echoes the opening,
transformed; the catalogue-level ring — the standing tell — never closes). Double-marked: attribution-first, Truby's seven
steps, audio-visual counterpoint.

**Why:** the operator is extending McKee's framework to the YouTube era —
classical architecture carries the video, platform tactics fill the minutes;
either alone fails ("surface-level retention tactics collapse under
narrative weight").

**How to apply:**
- Every script alternates Glass's anecdote (chronological bait raising
  unresolved questions) with reflection (why it matters). The RATIO shifts
  by phase, the alternation never stops. All-anecdote = shallow list;
  all-reflection = lecture.
- Tricolon on thesis-grade lines only (third stroke completes or subverts —
  the subversion is the humor turn); anaphora holds the opening constant so
  ends carry the change; both converge in a final closing triad.
- Hard gates, not style notes: attribution-first (frame before assertion),
  active S-V-O, one idea per sentence, terminal stress, punctuation as
  performance notation ("the script is a score, not prose").
- Narration must never caption its own visual (counterpoint — double-marked).
- Sentence-strength pass is STANDING (operator A/B verdict 2026-08-24:
  strength-passed arm won by ear on matched seed-locked TTS pairs). Ten
  gates in the kit's SENTENCE-STRENGTH-CHECK; biggest audible wins:
  terminal stress reorders, bait-question kills, active agents ("they
  sold you"), split run-ons.
