On Steel and Paper (2026-09-07) the operator dropped a line from a script that had already been recorded (SCRIPT-G) while
the opening also needed a rewrite. The agent did not patch G: both calls went into one artifact, `REWRITE-ORDER-H.md`,
and the changes into the next letter. The operator's reading of that lesson (2026-09-13): *"i think was more so about
trying to do patch work on a script that needed multiple edits."*

**Why:** patchwork on a script that needs several edits leaves a text no one wrote as a whole - each patch fits its gate
and the sentences around it stop agreeing (see [gate-fit-mangles-prose](gate-fit-mangles-prose.md)); and a recorded take's script is the record
its timeline aligns to, so patching it also desynchronises the audio.

**How to apply:** when more than one change is due, write them into a rewrite order (what changes, why, what is out of
scope) and draft the next letter from it; leave the previous letter and its take byte-identical. A single typo-level fix
to an unrecorded draft is not patchwork.
