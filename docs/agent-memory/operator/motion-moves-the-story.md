The operator, on whether a rescale/extend counts for the pacing gate: "the real question is are we also moving along the narrative and calling out a new thing by that movement ... true motion doesnt just move the visual it moves the story/narrative/thought process along."

**Why:** pacing is about the viewer's thought advancing, not pixels changing; a geometric test (did the chart change?) mis-counts both ways.

**How to apply:** when judging or gating motion, ask two things - is it on its spoken word, and does it bring a new thing on screen (new data, a label/badge/callout that names what the move shows)? Count it if both; a re-fit that names nothing is not an arrival. Recasts always count. Built as P69 T26c2.
