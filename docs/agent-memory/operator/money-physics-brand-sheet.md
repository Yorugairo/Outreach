`content/video_engine/channel-assets/money-physics/BRAND-SHEET.md` is the
one-page brand for Money Physics (assembled 2026-09-02), with
`brand-tokens.json` (W3C design-token format) and `design-system/` (Claude
Design preview cards with `@dsCard` markers, tokens.json, reference
assets). Every rule on the sheet cites its governing file: the style spine
(`projects/systems-and-blowups/style-spine.woodblock-vox-newsprint.v2.md`),
`configs/style_packs/woodblock.json`, doc 29, DOCTRINE-CORE.

Three registers, by decision: world plates = woodblock vox newsprint
(six fixed hex tokens, no text on plates, no washi/collage, host in-world);
evidence = near-black real charts with the source printed; packaging =
YouTube's own register (Impact-class outlined type, robo host, white
ground). `style-profile.v1.json` (crinkle-cut collage) is retired.

Claude Design push: DesignSync needs `/design-login` run once from an
interactive Claude Code session on this machine; the bundle README has the
plan. See [channel-structure](channel-structure.md), [production-standards-universal](production-standards-universal.md).

The sheet's §8b carries the settled ledger-page signature (2026-09-03:
cream ground, charcoal to the deckle, line at the deckle's innermost
rectangle, punch + focus); the ruling itself is [ledger-page-signature](ledger-page-signature.md).
