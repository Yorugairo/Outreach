## Repeated grammar worth adapting

1. **Keep the chart while its question advances.** The base plot, axes, title, units and source remain a reading surface; later series, dates, regions, and endpoint marks alter attention without needlessly resetting the scene. The 2-fps focus passes support state order, not sub-frame easing.
2. **Make the datum earn its label.** Trace or bar first; then a local glow/ring/guide; then a concise value pill or conclusion. This is more informative than a number tile floating apart from the plotted point.
3. **Show inputs before a derived comparison.** The two bars or named figures appear before the bracket, multiple, or arithmetic result. In our cuts, every derived output still needs reproducible calculation and provenance.
4. **Change representation when the claim changes class.** An actor-flow or cycle schematic explains a proposed mechanism; a historical chart measures a sourced series; a dashed extension marks a conditional scenario. The videos sometimes visually blur these classes, so our version must label them explicitly.
5. **Move the camera only for a named target.** Most watched chart change is mark/build activity in a held frame. A tail zoom can make a current value legible after the full history has established context; it must preserve unit/date/source and not become an idle push.

Two distinctions need proof rather than an assumed new drawing engine: narration-keyed chart `DRAW_KEYS` is recorded as **built but unwired** (capability row 21), and the watched dual-unit/historical-to-scenario treatments do not themselves prove that our compiler enforces source/claim/scenario semantics. Use aligned small multiples by default when unlike axes could imply false correlation. The standing [camera ruling](../../portable/OPERATOR-RULINGS.md) keeps charts locked by default and disallows a continuous push on a held chart; a targeted, authored focus move is a separate decision.

## First bounded tests for Claude’s chart lane

1. Build one owned-data, 20–30 second chart beat: sourced line → narrated datum → endpoint ring/guide/pill. Compare time-only entry with word-keyed `DRAW_KEYS`; inspect cold seeks and phone-size labels.
2. Build one held-chart state change: full history → selected series/epoch → terminal zoom and badge. Require legend, scale, date window, source and caption-safe region to survive in both 16:9 and 9:16.
3. Build one comparison: two raw measures → intentional read hold → bracket → derived ratio. Compiler verifies arithmetic and sources; the ratio never arrives before its inputs.
4. Build one history/scenario boundary: solid observed line ends, separately labeled dashed conditional continuation begins, mechanism icons remain explanatory rather than plotted data. Blind-review whether the distinction reads without narration.

These tests inform finance-chart craft. They do **not** change the approved shared 2.5D/3D model-engine plan: Blender remains the editable scene/rig authoring backend, and all rendered media/layers still enter the same editorial player.
