## EFFECTS / STYLE — reusable observations, not asset copying

- Charcoal/near-black chart field; restrained axes; saturated series strokes; low, local glow around the active line rather than a whole-panel bloom.
- Endpoint percent values use compact filled pills and thin leaders/braces; selected periods use a ring, translucent vertical band, or magnifier. The meaning is carried by placement and linkage, not color alone.
- A “new fact” tends to be a single accent object (number, band, card, badge) over a chart already in place. The comparison chart’s `6x` arrives after two bars and a bracket; it is not the first evidence shown.
- Perspective/depth is modest: glow, translucent fill, floating card, and magnifier are the main spatial cues. Avoid tracing the Bravos-specific typography, icon art, exact palette values, chart data, or badge design; transfer sequencing/relationships only.
- Stroke widths, font family, pixel spacing, and exact glow radius were not measured from 512/1024 px contact sheets. Treat any apparent pixel value as unverified.
