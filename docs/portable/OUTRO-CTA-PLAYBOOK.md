## The rules

1. **ONE CTA per outro. Never three.** "Like, comment AND subscribe"
   destroys conversion through decision fatigue — pick the single
   action that matters most for THIS video and ask only for that.
   → Script H (as G): subscribe only, no like ask anywhere. ALIGNED.
2. **Value reinforcement BEFORE any ask** — "now you know X, Y, Z,"
   named specifically, never "thanks for watching."
   → Script H (as G): "You now have the test — three questions, thirty
   seconds, any holding." ALIGNED.
3. **Clear direction = a SPECIFIC subscribe reason.** "Subscribe so
   you don't miss next week's breakdown of [topic]" beats "subscribe
   if you liked this."
   → Script H (as G): "Subscribe for the watch: the week either tripwire
   moves — Bravos' at five and a half, mine on memory — that video
   posts." ALIGNED (arguably stronger: the reason is a standing
   instrument, not one video).
4. **Future pacing** — name what lands next and when.
   → Script H (as G): "the yardstick reading lands every quarter." ALIGNED.
5. **Peak-end theory** — the ending retroactively colors the whole
   video; a weak close makes everything before it feel worse. The
   outro template for educational content is the VALUE BRIDGE:
   reinforce value → future pace → clear CTA → end-card direction.

## End-screen SOP (the 20 seconds)

Full 20s end screen carrying: a subscribe button + the most recent
video + the best-performing video.

**Episode-one adaptation** (no catalog yet): subscribe button + one
slot pointed at the channel trailer or "next episode" placeholder;
retrofit to the SOP (recent + best) from episode three onward. The
narration's last line (Script H: "the certificate stays on the desk")
lands BEFORE the end screen; nothing new is spoken over it.

**Shorts differ (E41 §2).** The brand line *"Not a panic. Not a plot.
Mechanics."* is a channel asset, recorded once and stitched onto the
outro; a script never writes the triad (S07 FAILs it on a short). The
long form's final triad (P6) is a different device and stays.

## Explicitly NOT imported

AOY's general pacing benchmark (visual change every 1.4–1.6s) is for
the stock-footage lane and is still not imported as a cut rate. What
replaces "keep our hold rules" is E69 (2026-09-12): hold length is not
a defect, a dead frame is. Past 20 s the gate (M05) reads the longest
gap between visual events INSIDE the hold, against the pulse a short
already carries (a visual event every 1.2-2.5 s, M16) or the long
form's working target (8 s, M02); a species, a page beat, a chart state
change, a card or stage captions all count. A still world held past
20 s with nothing on it still fails.
