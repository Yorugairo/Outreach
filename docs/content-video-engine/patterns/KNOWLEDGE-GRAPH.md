# The Script Knowledge Graph

The operator's closing read of the 45-mark session: *"you can see the
knowledge graph / relational tree of how the Art of Youtube fills in and how
these specific practices inter-link in a fashion that we can use to execute
high quality, information-dense, and technically sound scripts that should
be significantly better than standard AI generation or basic human scripts."*

That IS the edge. Standard AI generation knows these devices as unrelated
tips; a basic human script knows a few by instinct. The advantage is the
**edges** — every device knows what it fills, what enforces it, and what it
becomes at other scales. This file is the edge list. The map
([FULL-VIDEO-MAP.md](FULL-VIDEO-MAP.md)) is the graph laid out in time; this
is the graph laid out by relation, and it is the design principle for the
kit's injection context (P10 T3): **inject relations, not rule lists.**

Emphasis tier from the marked session: **Glass dual engine · syntactical
triads/anaphora · ring composition (triple-marked)**. Double-marked:
attribution-first · Truby's seven steps · A/V counterpoint.

## 2. Scale-free devices (work identically at every level — the strongest class)

- **Terminal stress**: surprising word ends the sentence → best evidence
  sits at the retention peak (point ordering) → the ring echo ends the
  video. One principle, three altitudes.
- **Attribution-first**: frame before assertion at sentence scale → the
  answer format's Credit beat at video scale (name Bravos before the
  claim). Same physics.
- **The gap**: BUT connectors → head-fakes → midpoint reversal → the
  answer format's Relocate beat (audience expects agreement or refutation,
  gets relocation).
- **The triad**: three strokes at line scale (third completes or subverts —
  the subverted third IS the Chappelle humor turn, persona §4) → three
  foreshadows at video scale → the closing anaphoric triad fuses both.
- **The ring**: callback tokens LIFO at video scale → the catalogue's
  standing tell at channel scale (every video reopens the same threshold
  watch — the ring that never fully closes is what brings viewers back).

## 3. Cross-links that prevent the classic failure modes

| Failure mode | Prevented by the edge |
| --- | --- |
| Tactics-only collapse ("retention tricks, no substance") | every micro device hangs on a classical load-bearing node — rehooks re-justify a REAL open question, not noise |
| Classical vagueness ("great structure, dead minutes") | every phase carries counted micro duties (map §9 roster) |
| AI-slop register | the score is lintable; personality mechanisms are rationed by the voice profile |
| Trendy-format decay | archetype-vs-stereotype: universal experience in a specific setting outlives the format wave |
| Lecture drift (finance risk) | Glass alternation never stops; reflection density capped by phase ratio |
| Fact-dump drift | anecdote must keep raising unresolved questions — information rides tension, or it waits |

## 4. Execution consequence

A script generated from this graph differs from standard generation in a
testable way: every line can answer three questions — *which classical node
am I serving, which micro duty am I discharging, and at what scale does my
device repeat?* Lines that answer none get cut. That triple-accountability
is the quality mechanism, and it is what the phase guides (T2) template and
the lints (T4) partially automate.
