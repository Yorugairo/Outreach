This file is the **seed a reader authors**, and the only place a device or an
exemplar ever enters. `content/video_engine/scripts/build_craft_map.py` joins
it to `docs/GATES-REGISTRY.jsonl` (what enforces the device) and to

## The row format

| column | rule |
| --- | --- |
| **device** | the canonical short name. It is also the phrase the generator matches against gate rule text, so name it as the docs name it |
| **scale** | one or more of `L0`–`L6` per `STRENGTH-LOOP.md` §1 — L0 line · L1 phrase · L2 beat/loop · L3 unit/section · L4 phase · L5 video · L6 catalogue. Macro = L4–L6, micro = L0–L3; a device carrying both is **scale-free** (`KNOWLEDGE-GRAPH.md` §2) and appears in both blocks of the map. Add `judge` when no tool decides it |
| **what it does** | ≤ 140 characters, in the docs' words |
| **defined in** | one or more `path#Heading`, separated by `; `. The heading may be a prefix; the generator resolves it to a line |
| **exemplar** | `"verbatim line" (path:line)` — a line you can `rg` at that path — or `none found (roots searched: …)`. Never invent one |

Order is deliberate: the table walks the video (package → P1 → P2 → P3 → P4 →
P5 → P6), then the cross-phase constants, then line craft, then the catalogue
scale, then the shorts lane.
